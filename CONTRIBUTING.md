# Contributing to MITS Attendance Tracker

Thank you for your interest in improving MITS Attendance Tracker!

## 🛠️ Development Workflow
1. **Fork & Clone** the repository:
   ```bash
   git clone https://github.com/manojreddyvantla/ATTENDANCE-TRACKER.git
   ```
2. **Install Dependencies**:
   ```bash
   npm install
   ```
3. **Run Dev Server**:
   ```bash
   npm run dev
   ```
4. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
5. **Test Build**:
   ```bash
   npm run build
   ```
6. **Submit a Pull Request**.

## 📌 Code Style
- Use clean, semantic Next.js 16 App Router patterns.
- Follow mobile-first responsive design standards.
