# Changelog

All notable changes to **MITS Attendance Tracker** will be documented in this file.

## [1.0.0] - 2026-08-18

### Added
- Real-time GEMS attendance scraping integration via dedicated Next.js API route.
- Interactive Dashboard with overall attendance, target progress bar, and safe bunks calculation.
- Enrolled subject card grid with search query filtering and Safe / Shortage filter tabs.
- Live sync button to refresh attendance without re-logging in.
- Developer attribution badges and MITS branding.
- Multi-environment Render and Vercel deployment support with `render.yaml`.
