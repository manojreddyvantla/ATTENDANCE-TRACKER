# Security & Data Privacy Policy

## 🔒 Credentials & Data Privacy
- **Zero Credential Persistence**: MITS GEMS student credentials (passwords) are strictly used in-flight during the authentication session and are never stored in databases or server logs.
- **Client Session Isolation**: Active session data resides inside the student's browser `sessionStorage` and is cleared upon clicking **Sign Out** or closing the browser tab.
- **Encrypted Transmission**: All communication between client, backend API, and scraping services utilizes end-to-end TLS/HTTPS encryption.

## 🛡️ Responsible Disclosure
If you identify any security concerns or edge cases in the scraping interface, please report directly to the repository maintainer.
